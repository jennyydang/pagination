Pagination component

The six required layouts below are static illustrations. Further down are two examples, both the exact same c-pagination markup, styling, and pagination.js — the only difference is one HTML attribute. By default a page number is a plain anchor: pagination.js lets it follow its href like any other link. Add data-mode="ajax" to the component and it takes over those same clicks itself instead, pushing the URL and re-rendering in place. One example below is labeled SSR (no data-mode, so every page click is a genuine full-page navigation); the other is labeled AJAX (data-mode="ajax", plus a pagination:navigate listener the host page uses to keep a results list in sync). Arrows and the mobile input have no href to fall back on, so they always navigate via JavaScript regardless of mode. Try clicking through pages, hovering an ellipsis, or resizing either example below ~800px to see the compact < 1 / 50 > mobile layout.

Example SSR

The exact same c-pagination markup, CSS, and pagination.js as the AJAX example below — this instance just has no data-mode attribute, which is pagination.js's default. View source and you'll see the page list, the current page, and the disabled prev arrow are all plain, real HTML from the first byte. Without data-mode="ajax", clicking a page number does the anchor's default thing — a genuine full-page navigation to ?page=N — whether or not JavaScript is running (try disabling it entirely; every page link still works). The prev/next arrows and mobile input still need JavaScript, since they have no href of their own to fall back on.

Example AJAX

The same c-pagination component as the SSR example above (500 results, 10 per page, so 50 pages), with one attribute added: data-mode="ajax". That's what makes pagination.js take over page-link and ellipsis clicks itself — pushing the URL and re-rendering its own page list — instead of letting them navigate normally. This page also listens for the pagination:navigate event pagination.js fires on every navigation to re-render the results list below to match, all with no reload.
