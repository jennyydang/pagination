Live demo

This is real, server-renderable markup: the initial page list below is hand-authored (no JavaScript needed for the first paint or for following a page link). pagination.js only wires up the arrows, the mobile "go to page" form, and re-renders the list on interaction. Every navigation also fires a pagination:navigate event you can intercept to fetch content over AJAX instead of letting the browser follow the link.
