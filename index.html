Pagination component

Resize the window (or open dev tools' device toolbar) to see the compact < 1 / 50 > mobile layout below ~640px. Hover or focus an ellipsis to see it swap to a jump control. Each example is a fully independent, self-initializing instance.

7. AJAX mode

This instance intercepts navigation instead of doing a full page load: it calls event.preventDefault() on pagination:navigate, "fetches" (simulated) new content, then calls pagination.update(...) to re-render in place and pushes a new URL with history.pushState.
